# Textures

All from [Poly Haven](https://polyhaven.com), CC0, 1k JPG: `diff` (albedo), `nor` (normal, GL), `rough` (roughness). The wall uses only its albedo.

| Folder | Used for | Poly Haven asset |
| --- | --- | --- |
| `floor/` | Gallery floor | [concrete_floor_worn_001](https://polyhaven.com/a/concrete_floor_worn_001) |
| `wall/` | Walls, lintels, door reveals | [beige_wall_001](https://polyhaven.com/a/beige_wall_001) |
| `plinth/` | White plinths and frames | [white_plaster_02](https://polyhaven.com/a/white_plaster_02) |
| `wood/` | Desk and doors | [white_oak_veneer](https://polyhaven.com/a/white_oak_veneer) |
| `jacaranda/` | Garden trees (bark, leaf atlas; 512 px, alpha split into its own JPEG) | [jacaranda_tree](https://polyhaven.com/a/jacaranda_tree) model textures |
